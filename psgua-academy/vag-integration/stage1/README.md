## Завантаження на хостинг (ADM.TOOLS → Файловий менеджер → папка сайту webinars.uaguides.com)
1. Спершу **збережіть копії** поточних `index.html`, `verify.html`, `room.html` (наприклад, перейменуйте на `*.bak`).
2. Завантажте 4 файли з `webinars-stage1-upload.zip`: три замінять старі, `academy-links.js` новий.
3. Відкрийте сайт і натисніть Ctrl+F5. Має з'явитися пункт «Академія» в меню і блок курсів.
Відкат: поверніть файли `*.bak`. Файл `academy-links.js` можна залишити, він нічого не ламає.

Повний список змін — `changes.diff`.
