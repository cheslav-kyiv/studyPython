# Вставка в Google Apps Script: посилання на Академію в листах

⚠ **Не замінюйте весь скрипт файлом `apps-script.gs` з архіву.** Сайт запитує розклад (`?schedule=1`), а в архівній версії скрипту такої функції немає. Отже, у Google працює новіша версія, і повна заміна її зламала б. Вносимо лише дві невеликі вставки.

## Як відкрити скрипт
Google Таблиця вебінарів → меню **Розширення → Apps Script**.

## Вставка 1: лист «Реєстрацію підтверджено»
Знайдіть (Ctrl+F) у функції `doPost` рядок листа-підтвердження з текстом
`'<p>З повагою,<br>Всеукраїнська асоціація гідів</p>'`
**у блоці, де `subject: 'Реєстрацію підтверджено: '`**. Безпосередньо **перед** ним вставте рядок:

```javascript
          '<p>Хочете заглибитися в тему? Онлайн-курси <a href="https://webinars.uaguides.com/#academy">Академії ВАГ</a> — у вашому темпі, із сертифікатом про завершення курсу.</p>' +
```

## Вставка 2: лист із сертифікатом учасника
Знайдіть у функції видачі сертифіката (`issueRow_`) такий самий рядок `'<p>З повагою,<br>Всеукраїнська асоціація гідів</p>',`
**у блоці, де `subject: 'Сертифікат учасника вебінару ВАГ: '`**. Безпосередньо **перед** ним вставте:

```javascript
        '<p><b>Наступний крок:</b> поглибте знання на онлайн-курсах <a href="https://webinars.uaguides.com/#academy">Академії ВАГ</a>. Курс завершується тестом і сертифікатом Академії — окремим документом про навчання.</p>' +
```

## Після вставки
1. **Збережіть** (значок дискети).
2. **Розгорнути → Керувати розгортаннями → ✏ (редагувати) → Версія: «Нова версія» → Розгорнути.** Адреса веб-застосунку при цьому **не змінюється**, тому сайт нічого не помітить.
3. Перевірка: у редакторі запустіть функцію `testDoPost`. На вашу пошту прийде тестовий лист-підтвердження з новим абзацом.

Якщо щось пішло не так: **Розгорнути → Керувати розгортаннями** → оберіть попередню версію. Сайт повернеться до старих листів.
