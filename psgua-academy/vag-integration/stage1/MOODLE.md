# Moodle (academy.psgua.com): посилання на вебінари

## 1. Пункт меню «Вебінари ВАГ»
1. Відкрийте (пошук налаштування за назвою, працює в будь-якій версії Moodle):
   `https://academy.psgua.com/admin/search.php?query=custommenuitems`
2. У полі **«Користувацькі пункти меню»** (Custom menu items) додайте окремим рядком:
   ```
   Вебінари ВАГ|https://webinars.uaguides.com/
   ```
3. **Зберегти зміни.** Пункт з'явиться у верхньому меню поруч із «На головну», «Мої курси».

## 2. Блок «Найближчі вебінари» на головній
Головна Академії → увімкнути **«Режим редагування»** → **«Додати блок»** → **«Текст»** (Text). Назва: `Вебінари ВАГ`. Текст:
> Безкоштовні онлайн-вебінари для гідів: розклад, реєстрація та сертифікати учасника — на **webinars.uaguides.com**.
(зробіть слова посиланням на `https://webinars.uaguides.com/`) → Зберегти.

## 3. Перевірити: чи відкриваються описи курсів без входу
Сайт вебінарів веде на `https://academy.psgua.com/course/info.php?id=2` і `…?id=3`. Відкрийте ці адреси **у вікні інкогніто**:
- видно опис курсу → ✅ усе гаразд;
- просить увійти → у пошуку налаштувань (`admin/search.php?query=forcelogin`) вимкнено «Примусовий вхід»? Якщо він увімкнений навмисно, скажіть мені, і я заміню посилання на головну Академії.

## 4. Перевірка сертифікатів курсів (для етапу 2)
Відкрийте `https://academy.psgua.com/mod/customcert/verify_certificate.php` у вікні інкогніто. Якщо бачите поле для коду, перевірка працює. Якщо ні: `admin/search.php?query=verifyallcertificates` → увімкнути.
