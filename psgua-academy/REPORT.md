## 5. Відкриті питання (перед запуском)

1. **URL розділів web.psgua.com у футері Академії** (`#about`, `#documents`, `#join`, `#contacts`) — припущення. Перевірте й виправте в `academy/*.html` (пошук `web.psgua.com/#`).
2. **`i.png`, `favicon.png`** — скопіювати з web.psgua.com у корінь academy.
3. **Endpoint форм** — зараз `mailto:`. Для серверного прийому вкажіть `FORM_ENDPOINT` в `assets/app.js` (POST JSON).
4. **Перевірка сертифікатів** чесно позначена як «за запитом»: онлайн-реєстр, Open Badges та ESCO мають статус 🔵 Заплановано. Не подавайте їх як працюючі (зокрема в заявці на DIGITAL SME Awards).
5. Дані Moodle (БД MySQL, `moodledata`, сертифікати, видані в Moodle) **не мігровано**. Перед вимкненням MoodleCloud експортуйте список виданих сертифікатів: він потрібен для перевірки за запитом.

## 6. Інструкція з розгортання на ADM.TOOLS

1. **Бекап.** Панель ADM.TOOLS → Хостинг → сайт `academy.psgua.com` → створіть резервну копію файлів і БД.
2. **Moodle → архів.** Через SSH (Хостинг → SSH-доступ) перейдіть у корінь сайту (зазвичай `~/psgua.com/academy/www` — перевірте шлях у панелі):
   ```bash
   bash migrate-moodle.sh
   ```
   ```bash
   bash migrate-moodle.sh --apply
   ```
   Без SSH: у Файловому менеджері створіть `_legacy_moodle_backup/` і перенесіть туди все. Обов'язково покладіть у неї `.htaccess` із рядком `Require all denied`, бо `config.php` містить пароль БД. **Найкраще перенести архів за межі `www`.**
3. **Завантаження.** Розпакуйте `academy-upload.zip` у корінь сайту (Файловий менеджер → Завантажити → Розпакувати). Переконайтеся, що `.htaccess` скопіювався: файли з крапкою на початку бувають приховані.
4. Покладіть `i.png` і `favicon.png` у корінь.
5. **SSL**: Хостинг → SSL → Let's Encrypt для `academy.psgua.com` (редирект на HTTPS уже є в `.htaccess`).
6. **Перевірка:** `https://academy.psgua.com/login/index.php` і `/course/view.php?id=2` мають давати 301 на головну; `/_legacy_moodle_backup/config.php` має давати 403.
7. Додайте `https://academy.psgua.com/sitemap.xml` у Google Search Console.
8. Запустіть `patch_web_psgua.py` на реальній папці web.psgua.com і завантажте змінені файли.
9. Вимкніть MoodleCloud `uaguides-memory` лише **після** експорту даних (§5.5).
